Ultra-Light Task Router for Online Navigation

Ultron

A plugin for an open-source browser agent. Tiny on-device models and a few short, bounded LLM calls handle the routine parts of the web, pop-ups and forms, and everything else goes to the full LLM agent.

What happens on each step

  1. Pop-upThe pop-up model picks a button. Below its 0.6 confidence gate, the LLM agent decides.
  2. FormThe forms model fills the text fields it is sure of, above a 0.9 gate.
  3. SettleOne short LLM call matches document lines to the remaining fields. It can pick a line or none, never free text.
  4. Required fieldsChecked in code. If a required value is missing, the run stops and names the field instead of inventing one.
  5. SubmitOne short call sees only the button labels, so planted page text can't steer it. A last call checks the page confirmed receipt.
  6. Hand-offPassword, file and card pages, fields a person can't see, and anything unsettled go to the full agent.

The model and gate were fixed before scoring, and it was scored once. When it answers, it is about as accurate as the best LLM at a tiny fraction of the compute, but it declines more often, 29 pop-ups against 4. Rules almost never click wrong because they answer only 101.

What didn't work

  • The tiny forms model isn't what creates the gain. Without it, Ultron handled 33 forms instead of 31, interval [−5, 0]. The routing design does the work.
  • A gate from conformal risk control (ICLR 2024) handled 32 against 31 for the fixed 0.9 gate, after losing 2 forms on the tuning set. Neither is clearly better.
  • Temperature scaling didn't help: the pop-up model was already calibrated, with an expected calibration error of 0.037.
  • Ultron fills more fields that should stay empty than the default agent, 16.7 against 5.3 per run, and doesn't answer choice controls.

Limits

  • Test pop-ups use dialog markup, which is what the detector looks for.
  • Token counts aren't dollars. Prompt caching would narrow the gap.
  • The LLMs are local 14B and 32B models, not frontier ones.
