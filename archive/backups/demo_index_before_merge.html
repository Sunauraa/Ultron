A tiny neural model that decides what a browser agent should do with a pop-up. It has 869,000 parameters and runs here in this tab. Nothing you type leaves your browser.

How it works

  • Two byte-level Transformers from Cua's S1 pipeline, 434K parameters each. Their probabilities are averaged, so disagreement lowers confidence and sends the pop-up to the LLM.
  • Trained on real pop-ups from 25,000+ public sites, plus LLM-written and template dialogs. Pages were only read: no clicks, and non-GET requests blocked.
  • An LLM classed each button, and the labels were kept when two passes reached the same action.
  • Removing a banner's best button teaches the order across languages: reject, then close, then accept.

Limits

  • 83% of the test is cookie banners. On other pop-ups it gets 73.5%, level with Qwen.
  • Only 18 test items have trap buttons, so the trap numbers are rough.
  • Qwen 14B is a local model, not a frontier one.
  • Most common error: clicking "accept all" when a reject option exists.
